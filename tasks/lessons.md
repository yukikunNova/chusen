# Lessons

## 2026-11-12 自動操作ブラウザは利用者に見えている

- 起きたこと: Playwright で撮影を連射している最中、利用者がそのウィンドウを見て「シーンが縮む・外側が激しく点滅・全体が白く明滅」と報告した。アプリの不具合ではなく、表示領域の固定（1280×720）と連続撮影の副作用だった
- 誤り: 自動操作ブラウザを headless だと思い込み、確かめずに「headless で計測」と報告していた
- 対策:
  - 自動操作を始める前に「別ウィンドウが勝手に動く。見た目の確認は自分のタブで」と利用者に伝える
  - headless かどうかは `navigator.userAgent` に `HeadlessChrome` があるかで確かめてから書く
  - 利用者に見てもらっている間は、撮影やファイル保存（Vite の自動再読込が走る）をしない
