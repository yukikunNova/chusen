# ドパ抽 — 発表順抽選

発表順をランダムに決めるブラウザアプリ。参加者がロケットになって宇宙を走り、ゴールした順が発表順になる。

- 順番は「抽選スタート」を押した瞬間に公平な乱数で確定する。レース中の追い抜きや攻撃アイテムは演出で、結果には影響しない
- 全員の順番が出そろうまで約 27 秒。スキップ（Space キー）ですぐ結果を出せる
- 対応ブラウザ: Chrome / Edge（パソコン）

## 使い方

1. 名前を入力して Enter。改行区切りの一覧をまとめて貼り付けてもよい（1 グループ 30 人まで）
2. その日いない人はスイッチをオフにする（抽選に参加できるのは 2〜20 人）
3. 「🚀 抽選スタート」を押す
4. 結果画面で「結果をコピー」を押すと、`1. 佐藤` の形式でチャットなどに貼れる

集まりごとに名簿を分けたいときは、グループを「＋」で追加してタブで切り替える。

音を消したいときは「🔊 音オン」を押す。設定は次回も引き継がれる。

## 名簿の保存について

- 名簿は**開いているブラウザの中**（localStorage）に保存される。サーバーには送らない
- 別のパソコン・別のブラウザ・別の URL では名簿は共有されない。移すときは「書き出し」で JSON ファイルを保存し、移動先で「読み込み」する
- ブラウザのサイトデータを消すと名簿も消える。大事な名簿は「書き出し」で控えを取っておく
- Safari では 7 日間開かないと名簿が消える場合がある（対応ブラウザは Chrome / Edge）

## 3D 表示が使えない環境

WebGL が使えないブラウザでは、順位を 1 行ずつ出す簡易表示で動く。抽選の公平性は同じ。

OS の「視差効果を減らす」が有効なときは、画面の揺れや点滅を弱める。

## 開発

Node.js 24 が必要。

```bash
npm install
npm run dev        # 開発サーバー
npm test           # テスト
npm run typecheck  # 型チェック
npm run format     # 書式をそろえる
npm run build      # 本番ビルド（dist/）
npm run preview    # 本番ビルドを手元で開く
```

`main` に push すると GitHub Actions が検証・ビルドして GitHub Pages に公開する（`.github/workflows/deploy.yml`）。

設計書は `docs/superpowers/specs/`、実装計画は `docs/superpowers/plans/` にある。
